## Notebook checklist

- State the section question and learning goal.
- Use an original, simulated, or properly licensed data set.
- Keep imports and setup in one early section.
- Run all cells from a fresh kernel before committing.
- Interpret every important table or figure in plain language.
- End with limitations and a link back to the matching note.
